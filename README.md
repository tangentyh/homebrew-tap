# Tangentyh Tap

## How do I install these casks?

`brew install --cask tangentyh/tap/<cask>`

Or `brew tap tangentyh/tap` and then `brew install --cask <cask>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tangentyh/tap"
cask "clashx-meta"
```

## How do I install these formulae?

`brew install tangentyh/tap/<formula>`

Or `brew tap tangentyh/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tangentyh/tap"
brew "<formula>"
```
